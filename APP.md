# Drink selection app

## Summary

A web app that lists common cocktail alcohol. 

The app should have 3 lists
- Ingredients: list of common cocktail alcohol
- Selected: list of user selected alcohol
- Cocktails: result of possible cocktails that can be made with the selected list

The user drags one (or many) alcohol from the "ingredient" list to a the "selected" list. The app then lists the cocktails that can be made with the items in the "selected" list. 

Both list of common alcohol and list of cocktails can be found here: https://en.wikipedia.org/wiki/List_of_cocktails

- The user can drag an alcohol from the "selected" list back to the "ingredient" list
- When the selected list is updated, the list of cocktail should be updated as well
